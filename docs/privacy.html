Privacy Policy

Last updated: September 24, 2026

Who uses this app

Channel Automation Tools is used only by its owner to manage YouTube channels that the owner owns. It is not a public service and does not have other users.

What data the app accesses

With the owner's permission, the app uses the YouTube Data API to upload videos, set titles, descriptions, thumbnails and playlists, and read basic information (channel name and ID) about the owner's own channels. It does not access any other person's data.

How data is stored

The access token for the owner's channels is kept as an encrypted secret in the owner's GitHub account and is used only to perform the actions above. No data is sold, shared with third parties or used for advertising.

Google API Services

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. YouTube API use follows the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
